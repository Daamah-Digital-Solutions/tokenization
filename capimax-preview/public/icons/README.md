# App Icons

This folder should contain the following icon files for PWA support:

- `icon-72.png` (72x72)
- `icon-96.png` (96x96)
- `icon-128.png` (128x128)
- `icon-144.png` (144x144)
- `icon-152.png` (152x152)
- `icon-192.png` (192x192) - also used as Apple touch icon
- `icon-384.png` (384x384)
- `icon-512.png` (512x512)

## Icon Requirements

1. All icons should be PNG format with transparent background
2. Use the Capimax RT logo centered on a dark navy (#0f172a) or emerald (#10b981) background
3. Icons at 192x192 and 512x512 should be "maskable" - meaning the important content should be in the center 80% of the image (safe zone)

## Generating Icons

You can use tools like:
- https://realfavicongenerator.net
- https://www.pwabuilder.com/imageGenerator
- Figma or Adobe Illustrator

Upload your base logo and generate all required sizes.
